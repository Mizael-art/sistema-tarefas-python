Sistema de gerenciamento de tarefas desenvolvido em Python utilizando SQLite como banco de dados.

O projeto foi criado com foco em praticar conceitos fundamentais de backend e persistência de dados, incluindo operações CRUD (Create, Read, Update e Delete).

Funcionalidades:

* Adicionar tarefas
* Listar tarefas
* Editar tarefas
* Marcar como concluídas
* Apagar tarefas

Tecnologias utilizadas:

* Python
* SQLite3
* SQL

Objetivos do projeto:

* Aprender integração entre Python e banco de dados
* Praticar comandos SQL
* Entender persistência de dados
* Evoluir habilidades de backend e lógica de programação
